Arrow Functions

This function takes a number as a parameter and doubles it by multiplying it by 2. I came up with it from scratch as a simple example of how a function can take a value, do something to it, and return the result.

Named Function

            function doubleIt(aNumber) {
                return aNumber * 2;
            }
 
            console.log(doubleIt(5));

Function Expression

            const doubleIt = function(aNumber) {
                return aNumber * 2;
            }
 
            console.log(doubleIt(5));

Arrow Function

            const doubleIt = (aNumber) => {
                return aNumber * 2;
            }
 
            console.log(doubleIt(5));
